# Async Patterns

Практика конкурентности на Go: горутины, каналы, синхронизация и отмена через контекст.

## Задачи

- [predictable behavior](<predictable behavior/>) — ограничение времени ожидания результата. Варианты: вызов одной медленной функции; параллельные HTTP-запросы с подсчётом успехов и ошибок; компактная реализация с одним каналом результатов.
- [Fan In](<Fan In/>) — объединение нескольких входных каналов в один выходной. Варианты: базовый; с отменой через контекст; с отменой и удалением дубликатов.
- [Tee](Tee/) — передача каждого входного значения в два выходных канала. Базовый вариант с закрытием обоих выходов после завершения входа.

Правила учебного взаимодействия и публикации находятся в [AGENTS.md](AGENTS.md).
